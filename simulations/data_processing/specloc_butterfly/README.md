# Spectral Localizer Butterfly Processing

## Overview

This directory contains simplified scripts for processing and visualizing spectral localizer (specloc) butterfly diagrams. Unlike the Majorana polarization butterfly (which requires extensive processing including normalization and discretization), the specloc butterfly simply plots the raw spectral localizer invariant values on a mu vs gamma (slope) parameter space.

## Files

- **main.jl** - Main driver script that orchestrates data loading, extraction, and plotting
- **processing.jl** - Module for loading JLD2 chunks and extracting specloc data
- **plotting.jl** - Module for creating heatmap visualizations of specloc values
- **README.md** - This file

## Data Structure

The raw data comes from `simulations/raw_data/specloc_butterfly/` and consists of JLD2 files organized by row index and chunk number:
```
_row{N}_thread_{T}_chunk_{C}.jld2
```

Each file contains a DataFrame with columns including:
- `N` - System size
- `t_n` - Hopping parameter vector
- `mu` - Chemical potential (x-axis of butterfly)
- `Delta` - Superconducting gap
- `sequence_id` - Tuple of (phi, phason) where:
  - `sequence_id[1]` = phi/slope parameter (y-axis of butterfly)
  - `sequence_id[2]` = phason angle
- `specloc_invariant` - Spectral localizer invariant (main quantity to plot)
- `specloc_gap` - Spectral localizer gap
- `kappa`, `x0` - Spectral localizer parameters

## Usage

### Basic Usage

```bash
cd simulations/data_processing/specloc_butterfly
julia main.jl
```

To plot one `x0` and choose the mu axis mode, pass `key=value` arguments:

```bash
julia main.jl x0=250.0 normalised=true
julia main.jl x0=250.0 normalised=false
julia main.jl x0=250.0 normalised=true svg
julia main.jl x0=250.0 normalised=true format=svg
julia main.jl x0=250.0 normalised=true svg colour=072f6b4d
julia main.jl x0=250.0 normalised=true svg nxn=3000
julia main.jl x0=250.0 normalised=true format=png colour=072f6bff nxn=2000 marker=square linewidth=2
```

`normalised=true` generates only the normalized plot; `normalised=false` generates only the raw plot. If `x0` is omitted, all x0 values are plotted. If both arguments are omitted, the script keeps its default behavior and generates raw and normalized plots for all x0 values, plus x0-averaged plots. Selecting a specific x0 skips the x0-averaged plots. Use `x0=all` to explicitly select every x0.

Output format defaults to PNG. Choose SVG or PDF with a bare format argument (`svg`, `pdf`) or `format=svg` / `format=pdf`. The selected extension is used for every plot generated by that run.

Set the non-white color endpoint with `colour=<hex>` (or `color=<hex>`). It accepts 6-digit RGB or 8-digit RGBA hex, with or without `#`; the default is `072f6b4d`. Zero remains white, and one uses the selected color.

Set a square output resolution in pixels with `nxn=<pixels>` (for example, `nxn=3000` produces a 3000×3000 plot). If omitted, the existing 1000×800 dimensions are retained.

For normalized scatter plots, set `marker=<shape>` and `linewidth=<size>`. Supported markers include `square`, `circle`, `diamond`, `cross`, and `x`. Since the normalized plot is made from scatter markers rather than line segments, `linewidth` controls marker size in points; the default is `1.0`. These options do not affect raw heatmaps.

### Configuration

Modify these variables in `main.jl` to change the data source:

```julia
data_folder = "hof_style_slopes_N1000_phason_0.0-1-0.0_..."  # Raw data folder name
folder_path_specloc = normpath(joinpath(...))                  # Full path to data
base_results_dir = normpath(joinpath(...))                     # Output directory
```

### Output

The script generates:
- **specloc_invariant_butterfly_*.png** - Heatmap of spectral localizer invariant vs (mu, phi)
- **specloc_gap_butterfly_*.png** - Heatmap of spectral localizer gap vs (mu, phi) [alternative view]

Plots use a white-to-blue colormap: invariant 0 is white and invariant 1 is blue.

## Implementation Notes

1. **Simplified Processing**: Unlike the IDOP scripts, no complex slicing, normalization, or discretization is performed. Data is plotted directly.

2. **Data Organization**: Data is automatically grouped by fixed parameters (N, Delta) and organized on mu vs phi axes.

3. **Memory Efficient**: Chunks are loaded sequentially rather than all at once.

4. **Error Handling**: Missing or invalid specloc values are skipped with warnings.

## Comparison with MB (Majorana Butterfly) Processing

| Aspect | MB Processing | Specloc Processing |
|--------|----------------|--------------------|
| Main quantity | Majorana polarization | Spectral localizer gap |
| Processing complexity | Complex (normalization, discretization) | Minimal |
| Slicing | Multi-dimensional slices | Simple (by Delta) |
| Coloring | Normalized MP values | Raw specloc gap |
| Output | Multiple projection plots | Direct butterfly heatmaps |

## Troubleshooting

### No data loaded
- Check that `data_folder` matches the actual folder name in `raw_data/specloc_butterfly/`
- Verify `.jld2` files exist in the target folder
- Check file permissions

### Missing columns
- Verify that JLD2 files contain expected columns (`specloc_gap`, `mu`, `phi`, etc.)
- Check column naming in `processing.jl` for alternate names

### Plot issues
- Ensure Plots.jl and GR backend are properly installed
- Check that output directory has write permissions
